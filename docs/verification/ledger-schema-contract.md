# PostgreSQL ledger schema experiment
Scope MOD-20: candidate SAD evidence, not approved production migration.
Acceptance: positive integer settlement, unique command per outlet, unique sequence per outlet and epoch, foreign key outlet membership, force RLS with authenticated database login scope, default deny absent scope, no update/delete permissions to runtime role. Test on PostgreSQL using non-owner role. No claims of exclusive writer fencing, authenticated scope binding, recovery or full payment service. Experiment uses distinct authenticated database logins mapped by a privileged administrator. This is a candidate security model, not an approved production pooling or staff authorization architecture. Custom session settings cannot change the mapping. Retry receipt semantics, active epoch fencing and concurrent replay remain separate unverified contracts.
