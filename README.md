# Bonaparte

Foundation and offline protocol experiment. The approved requirements are in docs/PRD_V1.0_FINAL.md. No deployment configuration or production credentials are included.

Run the dependency-free model tests with Node.js 24: `node --test tests/offline.test.mjs`.

The model is not a durable storage implementation. NestJS, Next.js, PostgreSQL, browser and gateway adapters remain pending. Do not use this model for real sales.
